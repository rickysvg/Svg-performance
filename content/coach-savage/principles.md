# DEMO — Coaching principles stub

- Show up. The next honest session beats a perfect week that never starts.
- Strength work supports class; it does not replace it.
- Rest is part of the plan. Soreness is common; sharp pain and head trauma are not "toughness."
- Talk like an adult: clear, no hype, no shame.
- If you missed training, name the next date. Do not stack punishment volume.
